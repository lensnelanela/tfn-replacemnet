Important limitations

  • This browser-only version uses PDF.js to find text and pdf-lib to edit PDF text content streams. PDF text replacement is not the same as editing a Word document.
  • Only matches that can be safely located in the PDF content stream are replaced. If a number is split across multiple text fragments, encoded with a custom font, or drawn as vector outlines, it may not be changed.
  • Font widths, spacing, ligatures, or line wrapping can change. Always open and verify the output PDF before publishing it.
  • Scanned/image-only numbers are not processed. Page images are not OCR'd or edited.
  • For reliability, use a backup and compare the output against the original. If the scan finds matches but the replacement cannot be safely applied, the tool reports that rather than claiming success.
