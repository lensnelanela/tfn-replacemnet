Important limitations

  • This tool works on selectable text, not scanned/image-only numbers.
  • Text is covered with a white rectangle and redrawn. This is not secure redaction and may not preserve the original font, colour, spacing, or background.
  • It handles matching numbers inside individual PDF text items. A number split across several items may be missed.
  • In each individual text item, the first match is replaced and subsequent matches are deleted. This is not necessarily the same as the first TFN in an entire paragraph.
  • Keep your original PDF as a backup and inspect the downloaded file before using it.
